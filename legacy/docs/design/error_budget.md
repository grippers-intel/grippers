# 오차 전파 분석 (Error Budget)

> 최종 파지·통과 정밀도가 어느 항목에 지배되는지 수치로 밝힌다.
> "왜 도킹 정밀도에 시간을 썼는가"에 대한 답이 여기서 나온다.

## 1. 오차 항목

| # | 항목 | 기호 | 값 (1σ) | 출처 |
|---|---|---|---|---|
| 1 | 도킹 정렬 오차 | σ_dock | | 실측 |
| 2 | 카메라 캘리브레이션 오차 | σ_cal | | 실측 |
| 3 | 깊이 추정 오차 | σ_depth | | RealSense 사양 + 실측 |
| 4 | IK 수치 오차 | σ_ik | | 시뮬레이션 |
| 5 | 서보 백래시 | σ_bl | | 실측 |
| 6 | 베이스 슬립 (통과 중) | σ_slip | | 실측 |

## 2. 합성

독립 가정 하에 RSS(Root Sum Square)로 합성한다.

```
σ_total = √(σ_dock² + σ_cal² + σ_depth² + σ_ik² + σ_bl²)
```

|---|---|---|

| σ_ik | | |

### 3-2. 개구부 통과

```
H_proj(φ) = L·|sin φ| + w·|cos φ| ≤ H_gap − margin
```

`L`, `w`, `H_gap` 모두 **추정값**이므로 margin은 추정 오차에 연동해야 한다.

| 항목 | 값 |
|---|---|
| σ_L (길이 추정) | |
| σ_w (폭 추정) | |
| σ_H (개구부 높이 추정) | |
| 권장 margin (≥ 3σ 합성) | |
| 채택 margin | |

> margin을 키우면 통과 실패는 줄지만 φ 해 구간이 좁아진다. 이 트레이드오프를 학습으로 결정하는 것이 본 프로젝트의 AI 필요성 근거다.
