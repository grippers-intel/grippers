====================================================================
 ArUco 로봇 위치찾기 - 처음부터 끝까지 따라하기
====================================================================

 이 프로그램은 뭘 하나요?
 --------------------------------
 옆에 세운 웹캠 2대가 바닥에 붙인 흑백 무늬(마커)를 보고,
 "로봇이 지금 어디에 있고 어느 쪽을 보고 있는지"를 밀리미터 단위로
 알아냅니다.

 전체 순서는 이렇습니다. 위에서부터 차례대로 하세요.

   1단계  마커 종이 인쇄하기
   2단계  카메라 번호 찾기
   3단계  카메라 눈 맞추기 (캘리브레이션)   <- 세우기 "전에"
   4단계  카메라 세우기
   5단계  바닥 마커 붙이기 (화면 보면서)
   6단계  로봇에 마커 붙이기
   7단계  자로 재서 숫자 적어두기
   8단계  컴퓨터에 숫자 넣기
   9단계  실행해서 확인하기

 카메라를 먼저 세우고, 화면으로 잘 보이는지 확인하면서 마커를 붙이는
 순서입니다. 그래야 붙였다 떼는 일이 없습니다.

 처음 하면 2~3시간 걸립니다. 서두르지 마세요.
 7단계(자로 재기)를 대충 하면 나머지가 전부 틀어집니다. 여기에 시간을
 제일 많이 쓰세요.


====================================================================
 준비물
====================================================================

 [ ] 웹캠(로지텍 C920) 2대
 [ ] 카메라 삼각대 2개
 [ ] 줄자 (5m 이상, 밀리미터 눈금 있는 것)
 [ ] 각도기 또는 각도 재는 휴대폰 앱
 [ ] 프린터, A4 용지
 [ ] 가위, 투명테이프 또는 양면테이프
 [ ] 연필 (마커 중심에 표시할 때 씁니다)
 [ ] 체스판 무늬 종이 (3단계에서 씁니다. 인터넷에 "체스보드 캘리브레이션
     9x6" 으로 검색해서 A4로 인쇄하면 됩니다)
 [ ] 마스킹테이프 (바닥에 표시할 때. 나중에 떼기 쉽습니다)


====================================================================
 잠깐, 좌표가 뭔가요?
====================================================================

 가벽으로 두른 공간은 가로 180cm, 세로 180cm 인 정사각형입니다.
 이 정사각형의 "앞쪽 왼쪽 구석"을 출발점(0,0)으로 정합니다.

   x = 출발점에서 오른쪽으로 몇 cm 갔는지
   y = 출발점에서 뒤쪽으로  몇 cm 갔는지

 예를 들어 "(40, 45)" 는 출발점에서 오른쪽으로 40cm, 뒤로 45cm 간
 자리입니다.

 이 출발점 구석에 테이프로 표시를 해두세요. 앞으로 모든 길이를
 여기서부터 잽니다. 중간에 바꾸면 전부 다시 재야 합니다.


 ★ 로봇이 다닐 수 있는 범위는 180 x 180 전부가 아닙니다

 앞쪽 벽과 뒤쪽 벽 옆 40cm 는 "상자 자리"로 빼둡니다.
 그래서 실제로 쓰는 작업 영역은 이렇습니다:

     가로(x) : 0 ~ 180 cm      <- 폭은 전부 사용
     세로(y) : 40 ~ 140 cm     <- 앞뒤로 40cm 씩 상자 자리

     즉 가로 180cm x 세로 100cm 인 직사각형

 그림으로 보면:

     ============================================  <- 뒤쪽 벽 (y=180)
     |  상자 자리 40cm    [장난감] [체스]        |
     |------------------------------------------|  y=140
     |                                          |
     |     로봇이 다니는 곳 + 옮길 물건들         |
     |          180 x 100 cm                    |
     |                                          |
     |------------------------------------------|  y=40
     |  (앞쪽 40cm 는 비워 둡니다)                |
     ============================================  <- 앞쪽 벽 (y=0)

 왜 40cm 인가요?
   상자 크기가 21 x 35 x 22 cm (폭 x 길이 x 높이) 라서,
   길이 35cm 짜리를 벽에 붙여 놓으면 35cm 를 차지합니다.
   여유 5cm 를 더해 40cm 를 상자 자리로 잡았습니다.

   상자 2개(장난감, 체스)는 둘 다 뒤쪽에 놓습니다.
   앞쪽 40cm 는 상자가 없지만, 카메라가 그 부근을 잘 못 보기 때문에
   똑같이 비워 둡니다.

 카메라도 이 부근을 잘 못 봅니다
   로봇 마커는 바닥이 아니라 로봇 위(20cm 높이)에 붙어 있어서,
   가벽(35cm)이 그 높이의 시선을 가로막습니다. 계산해보면
   카메라가 못 보는 구간은 앞뒤 약 15cm 씩입니다.
   상자 자리 40cm 가 그보다 넓으니, 상자 자리만 피하면
   카메라 사각은 저절로 피해집니다.

 작업 영역 안에는 로봇과 옮길 물건만 있습니다.
 상자는 전부 이 바깥에 있어서 로봇 마커를 가리지 않습니다.
 (실제로 계산해봤더니 상자 뒤 그림자는 2.4cm 밖에 안 되고,
  작업 영역 안에는 사각지대가 한 점도 없습니다)

 로봇이 이 범위를 벗어나면 화면에 노란 글씨로
 "OUT OF WORKSPACE" 라고 뜹니다.


====================================================================
 길이는 어디를 기준으로 재나요?  ★자주 묻는 질문★
====================================================================

 ※ 먼저 오해 하나 풀고 갑니다 ※

 "마커 4장이 작업 공간의 경계를 정하는 건가요?"  ->  아닙니다.

 마커 4장은 그냥 "기준점"입니다. 땅에 박은 말뚝 같은 것이라고 보세요.
 프로그램은 이 4점을 보고 "여기가 어디인지"를 알아냅니다.

 로봇이 다닐 수 있는 범위(180 x 100cm)는 마커가 정하는 게 아니라
 상자 자리와 카메라 시야가 정합니다. 이미 계산해서 넣어놨습니다.

 지금 권장 배치는 마커가 마침 작업 영역의 네 귀퉁이 근처에 오지만,
 그건 "제일 넓게 벌린 자리가 거기라서" 이지 경계를 그으려는 게
 아닙니다. 마커 사각형이 작업 영역보다 작아도 전혀 문제 없습니다.

     ============================================
     |  상자 자리     [장난감] [체스]           |
     |------------------------------------------|  y=140
     |  [3]------------------------------[4]    |  y=140
     |   |                                |     |
     |   |   <- 마커가 만드는 사각형        |     |
     |   |      (기준점일 뿐)              |     |
     |  [1]------------------------------[2]    |  y=40
     |------------------------------------------|
     |  (앞쪽 40cm 는 비워 둡니다)                |
     ============================================


 답: 마커의 "한가운데(중심)" 기준입니다.

 config.py 에 적는 좌표는 전부 마커 중심의 위치입니다.
 모서리도 아니고 종이 끝도 아닙니다. 검은 사각형의 정중앙입니다.

     +-------------------+
     |                   |
     |                   |
     |         X <-------|---- 여기까지의 거리를 잽니다
     |                   |
     |                   |
     +-------------------+

 마커끼리의 거리도 마찬가지로 "중심에서 중심까지" 입니다.


 중심을 어떻게 찾나요?

   (1) 인쇄한 종이를 대각선으로 한 번 접습니다 (모서리와 모서리를 맞춰서)
   (2) 펴서 반대 대각선으로 한 번 더 접습니다
   (3) 두 접힌 선이 만나는 점이 정중앙입니다
   (4) 거기에 연필로 작게 + 표시를 합니다

   ※ 접은 자국이 남으니 살짝만 접었다 펴세요. 마커가 우글거리면
     인식이 나빠집니다. 자로 재서 표시해도 됩니다
     (8cm 마커면 각 변에서 4cm, 12cm 마커면 6cm 되는 지점).


 붙이는 실전 순서 (이 순서가 제일 쉽습니다)

   (1) 바닥에 먼저 마스킹테이프로 + 십자 표시 4개를 만듭니다
       (5단계에 나오는 목표 좌표에)
   (2) 마커 중심의 + 표시를 바닥 십자에 맞춰서 붙입니다
   (3) 다 붙인 뒤에 실제 위치를 다시 재서 7단계 표에 적습니다

   (3)번을 꼭 하세요. 아무리 조심해도 몇 mm 는 어긋납니다.
   중요한 건 "정확한 자리에 붙이는 것"이 아니라
   "붙은 자리를 정확히 아는 것"입니다.


 얼마나 정확히 재야 하나요?

   재는 오차가 그대로 로봇 위치 오차가 됩니다. 거의 1:1 입니다.

       재는 오차        로봇 위치 오차
       ---------        --------------
        1 mm             약  1 mm
        2 mm             약  2 mm
        5 mm             약  5 mm
       10 mm             약 11 mm
       20 mm             약 22 mm   <- 목표 30mm 에 가까워짐

   목표가 30mm 이므로 5mm 이내로 재면 넉넉합니다.
   밀리미터 눈금 있는 줄자로 재면 충분한 정확도입니다.


 제대로 쟀는지 확인하는 두 가지 방법

   방법 1) 대각선 재보기 (그 자리에서 바로 확인)

     네 마커가 직사각형을 이루면 두 대각선 길이가 같아야 합니다.

         [3]-------[4]
          | \     / |
          |   \ /   |
          |   / \   |
          | /     \ |
         [1]-------[2]

     1번↔4번 거리와 2번↔3번 거리를 재서 비교하세요.
     차이가 5mm 이내면 잘 붙인 것입니다.

     기본 배치(아래 5단계)대로라면 두 대각선 모두 188.7cm 입니다.
     옆변은 1↔2 가 160cm, 1↔3 이 100cm 입니다.

   방법 2) reproj 숫자 보기 (프로그램이 알려주는 성적)

     9단계에서 화면에 나오는 reproj 숫자가 곧 "얼마나 잘 쟀는지" 입니다.
     숫자를 잘못 적으면 이 값이 올라갑니다.

         reproj 1.0 미만  ->  잘 쟀습니다 (오차 2~3mm 수준)
         reproj 1.0 ~ 2.0 ->  그럭저럭 (오차 5mm 수준)
         reproj 2.0 넘음  ->  다시 재세요 (오차 10mm 이상)
         reproj 3.0 넘음  ->  프로그램이 아예 값을 안 내놓습니다

     이 숫자 하나로 자기 검사가 됩니다. 꼭 확인하세요.


 마커 크기는 얼마나 정확해야 하나요?

   생각보다 관대합니다. 12.0cm 여야 하는데 12.2cm 로 인쇄돼도
   로봇 위치 오차는 0.1mm 도 안 늘어납니다.

   다만 잰 크기를 config.py 에 "정직하게" 적어야 합니다.
   실제 12.2cm 인데 12.0 이라고 적으면 reproj 가 올라갑니다.
   1cm 이상 다르면 프로그램이 거부합니다.

   결론: 인쇄 크기를 억지로 맞추려 애쓰지 말고,
        나온 크기를 정확히 재서 그대로 적으세요.


====================================================================
 로봇이 바닥 마커를 밟고 서도 되나요?  ★자주 묻는 질문★
====================================================================

 답: 됩니다. 걱정 안 하셔도 됩니다.

 상자 앞에 서서 팔을 뻗어 물건을 내려놓을 때, 로봇이 3번(또는 4번)
 마커를 밟거나 가리게 됩니다. 계산해 봤더니 문제가 없습니다.

 이유는 두 가지입니다.

 (1) 마커 한 장쯤 가려도 나머지로 계산됩니다

       보이는 마커      위치 오차
       ----------      ---------
        4장            0.9 mm
        3장            1.6 mm
        2장            2.3 mm
        1장            계산 불가 (LOST)

     한 장 가려져도 목표 30mm 에 한참 못 미칩니다.
     로봇이 아무리 커도 160cm 떨어진 두 마커를 동시에 가릴 수는
     없으니, 최소 3장은 남습니다.

     ※ 권장 배치대로라면 상자가 마커에서 좌우로 35cm 떨어져 있어서
       애초에 로봇이 마커를 밟을 일도 거의 없습니다.

 (2) 프로그램이 카메라 위치를 "고정"해서 씁니다  <- 더 중요

     카메라는 삼각대에 고정돼 있으니 "카메라가 어디 있는지"는
     한 번만 계산하면 됩니다. 그래서 프로그램은 시작할 때
     4장이 다 보이는 화면 30장을 모아서 평균을 낸 뒤, 그 값으로
     고정합니다.

     고정한 다음에는 바닥 마커를 아예 안 봐도 됩니다.
     로봇 마커만 보이면 계속 추적합니다.

     실제로 측정한 결과:

         바닥 마커 4장 전부 가려짐  ->  추적 유지, 오차 0.21 mm

     게다가 30장을 평균내므로 매 프레임 다시 계산하는 것보다
     오히려 더 정확합니다:

         매 프레임 재계산 : 오차 평균 0.84 mm, 최대 2.39 mm
         고정 사용        : 오차 평균 0.29 mm, 최대 0.68 mm

 화면에서 확인하는 법
   카메라 화면 위쪽에 이렇게 표시됩니다:

       [locking 12/30]  <- 아직 모으는 중
       [LOCKED]         <- 고정 완료. 이제 마커를 가려도 됩니다

   프로그램을 켜고 1~2초면 LOCKED 가 됩니다.
   그때까지는 바닥 마커 4장이 다 보이게 두세요.

 ※ 카메라를 건드리면?
   고정한 값이 안 맞게 되므로, 프로그램이 스스로 알아채고
   고정을 풀어 다시 계산합니다. 하지만 그 사이 좌표가 틀리니
   카메라는 건드리지 않는 게 좋습니다.


====================================================================
 마커 방향 이야기 (동서남북 = 상하좌우?)
====================================================================

 결론부터: 네, 그렇게 생각하시면 됩니다. 단 조건이 하나 있습니다.

 기준은 "카메라가 보는 화면"이 아니라 "인쇄한 종이 자신의 위아래"입니다.

 마커 무늬는 그냥 흑백 네모가 아니라, 어느 쪽이 위인지가 무늬 자체에
 새겨져 있습니다. 그래서 종이를 옆으로 돌려 붙이든, 카메라가 비스듬히
 보든, 프로그램은 그 종이의 "위쪽"이 어디인지 항상 알아냅니다.
 (실제로 시험해서 확인한 내용입니다)

 그러니까 종이를 어느 방향으로 붙이느냐가 그대로 결과에 반영됩니다.

 이 프로그램에서 정한 약속은 이렇습니다:

      종이 위쪽   =  뒤쪽 (북)      y 가 커지는 방향
      종이 아래쪽 =  앞쪽 (남)      y 가 작아지는 방향
      종이 오른쪽 =  오른쪽 (동)    x 가 커지는 방향
      종이 왼쪽   =  왼쪽 (서)      x 가 작아지는 방향

 그림으로 보면 (위에서 내려다본 모습):

                    북 (뒤쪽 벽)
                        ^
                        |
              +-------------------+
              |    종이 위쪽      |
              |                   |
       서 <---|     [마커무늬]    |---> 동
              |                   |
              |    종이 아래쪽    |
              +-------------------+
                        |
                        v
                    남 (앞쪽 벽)

 바닥 마커 4장은 전부 이 약속대로 붙이면 됩니다.
 즉 네 장 모두 종이 위쪽이 뒤쪽 벽을 향하게.

 ※ 로봇에 붙이는 마커(0번)만 규칙이 다릅니다.
   로봇은 움직이면서 방향이 계속 바뀌니까, 바닥 기준이 아니라
   "로봇 몸통 기준"으로 붙입니다. 자세한 건 6단계를 보세요.


====================================================================
 1단계. 마커 종이 인쇄하기
====================================================================

 이 폴더 안에 이런 그림 파일 5개가 이미 있습니다.

   marker_0_robot.png     <- 로봇 위에 붙일 것
   marker_1_floor_1.png   <- 바닥 1번
   marker_2_floor_2.png   <- 바닥 2번
   marker_3_floor_3.png   <- 바닥 3번
   marker_4_floor_4.png   <- 바닥 4번

 (1) 파일을 더블클릭해서 열고 인쇄를 누릅니다.

 (2) 인쇄 설정에서 "실제 크기" 또는 "100%" 를 고릅니다.
     "용지에 맞춤" 은 고르면 안 됩니다. 다섯 장 크기가 제각각이 됩니다.

 (3) 인쇄한 뒤 자로 재세요. 크기가 두 가지입니다.

       marker_0 (로봇용)   -> 검은 사각형 8cm   (종이는 10cm, 여백 1cm)
       marker_1 ~ 4 (바닥) -> 검은 사각형 12cm

     * 재는 곳은 "검은 테두리의 바깥쪽 변" 입니다. 흰 여백은 빼고 재세요.
     * 딱 8.0 / 12.0 이 아니어도 괜찮습니다. 7.9 든 12.3 이든,
       그 숫자를 7단계에 적어두었다가 8단계에서 그대로 넣으면 됩니다.

     왜 로봇용만 작나요?
       로봇 상판이 좁아서입니다. 8cm 로도 작업 영역 전 지점에서 잘
       검출됩니다 (실제 검출기로 확인). 각도 정밀도도 0.73도로
       목표 3도에 여유가 큽니다.

       다만 로봇이 빨리 움직여 화면이 흔들릴 때, 12cm 보다 놓칠
       확률이 조금 높습니다. 놓쳐도 1초 동안은 마지막 값을 유지하니
       괜찮지만, 급가속·급회전은 피하는 게 좋습니다.

 (4) 너무 작게 나왔으면 배율을 올려 다시 인쇄하세요.
     예: 8cm 를 원하는데 7.3cm 가 나왔다면
         8.0 ÷ 7.3 = 1.10  ->  배율 110% 로 다시 인쇄

 (5) 종이를 대각선으로 두 번 살짝 접어 중심을 찾고 연필로 + 표시.
     (위의 "길이는 어디를 기준으로" 참고)

 (6) 검은 사각형 바깥으로 흰 여백을 2cm 정도 남기고 가위로 오립니다.
     흰 여백을 남겨야 카메라가 마커를 잘 찾습니다. 검은 선에 딱 붙여
     자르면 안 됩니다.

 (7) 종이가 우글거리지 않게 평평하게 펴두세요. 휘면 위치가 틀어집니다.


====================================================================
 2단계. 카메라 번호 찾기
====================================================================

 컴퓨터는 카메라를 이름이 아니라 번호로 부릅니다. 몇 번인지 확인합니다.

 (1) 웹캠 2대를 USB 에 꽂습니다.

 (2) 이 폴더에서 주소창을 클릭하고 cmd 라고 친 뒤 엔터를 누릅니다.
     (검은 창이 뜹니다. 이게 명령 프롬프트입니다)

 (3) 아래를 그대로 복사해서 붙여넣고 엔터:

python -c "import cv2; print([i for i in range(6) if cv2.VideoCapture(i, cv2.CAP_DSHOW).isOpened()])"

 (4) 이런 게 나옵니다:  [0, 1]
     이 숫자가 카메라 번호입니다. 대부분 0 과 1 입니다.
     만약 [1, 2] 처럼 다르게 나오면 그 숫자를 기억해두세요.
     앞으로 나오는 모든 명령 뒤에 --cams 1 2 를 붙이면 됩니다.

 ※ 노트북 내장 카메라가 있으면 그게 0번을 차지합니다.
   그럴 땐 웹캠이 1번, 2번이 됩니다.


====================================================================
 3단계. 카메라 눈 맞추기 (캘리브레이션)
====================================================================

 카메라 렌즈는 사진을 아주 살짝 휘게 찍습니다. 그 휘어진 정도를
 컴퓨터에 알려주는 작업입니다. 안 하면 위치가 몇 cm씩 틀립니다.

 ★ 삼각대에 세우기 "전에" 하세요.
   책상 위에서 카메라를 두고 하는 게 훨씬 편합니다.
   세운 다음에 하면 카메라를 건드릴 위험이 있습니다.

 ★ C920 은 오토포커스가 있습니다. calibrate_camera.py 가 시작할 때
   자동으로 꺼주지만(고정초점), 캘리브레이션 도중 렌즈를 만지거나
   초점 링을 돌리면 안 됩니다. 초점이 바뀌면 이 단계를 처음부터
   다시 해야 합니다.

 (1) 체스판 무늬 종이를 A4로 인쇄해서 딱딱한 판(책받침, 클립보드)에
     평평하게 붙입니다.

 (2) 자로 체스판 한 칸의 크기를 잽니다. 보통 2.5cm 입니다.
     다르면 아래 명령의 0.025 자리를 바꿔 적으세요. (2.0cm 이면 0.020)

 (3) 검은 창에 아래를 치고 엔터:

python calibrate_camera.py --cam 0 --square 0.025

 (4) 카메라 화면이 뜹니다. 체스판을 카메라 앞에 들고 보여주세요.
     무늬 위에 알록달록한 선이 그려지면 잘 잡힌 겁니다.

 (5) 잘 잡힌 상태에서 스페이스바를 누릅니다. 사진 한 장이 저장됩니다.

 (6) 체스판을 이리저리 움직이면서 20장 정도 찍으세요.
     같은 자세로만 찍으면 안 됩니다. 이렇게 바꿔가며 찍으세요:
       - 화면 가운데 / 왼쪽 / 오른쪽 / 위 / 아래
       - 가까이 / 멀리
       - 똑바로 / 왼쪽으로 기울여서 / 오른쪽으로 기울여서
       - 위로 젖혀서 / 아래로 숙여서

 (7) 20장쯤 찍었으면 c 키를 누릅니다. 계산이 끝나면 결과가 나옵니다.

     "RMS : 0.3xxx px" 처럼 나오는데
       0.6 보다 작으면    -> 잘 된 겁니다. 다음으로 넘어가세요.
       0.6 보다 크면      -> 경고가 뜹니다. 다시 찍으세요.

 (8) 두 번째 카메라도 똑같이 합니다. 번호만 바꾸세요:

python calibrate_camera.py --cam 1 --square 0.025

 (9) 다 끝나면 이 폴더 안에 calib 이라는 폴더가 생기고 그 안에
     cam0.npz, cam1.npz 파일이 들어 있어야 합니다. 확인하세요.

 ※ 이 작업은 한 번만 하면 됩니다. 다음부터는 건너뛰어도 됩니다.
    단, 카메라를 바꾸거나 렌즈를 만졌으면 다시 해야 합니다.

 ※ 두 카메라를 헷갈리지 마세요. 0번으로 캘리브레이션한 카메라를
    나중에 1번 자리에 꽂으면 안 됩니다. 몸통에 스티커로 0, 1 을
    붙여두면 좋습니다.


====================================================================
 4단계. 카메라 세우기
====================================================================

 카메라는 작업 공간 "바깥"에 섭니다. 안에 들어오면 안 됩니다.

 두 대를 서로 마주보게 놓습니다. (C920 교체 후 2026-08-23 갱신)

   카메라 A : 앞쪽 벽 바로 앞 (후퇴 없음, 0cm), 좌우로는 한가운데(90cm)
   카메라 B : 뒤쪽 벽 바로 앞 (후퇴 없음, 0cm), 좌우로는 한가운데(90cm)

   ("바깥으로" 는 작업 공간에서 멀어지는 쪽입니다. 두 대가 작업 공간을
    사이에 두고 서로 마주보게 됩니다. C270 때는 95cm 를 뒤로 뺐지만
    C920 은 화각이 넓어서 뺄 필요가 없어졌습니다)

   두 대 모두
     높이   : 바닥에서 렌즈까지 162cm
     각도   : 정확히 재지는 않았지만, 시뮬레이션(selftest.py)으로
              확인한 결과 40도 ~ 78도 사이 어디든 사각지대가 생기지
              않습니다. 대략 43도 근방(예전과 비슷하게)이면 충분합니다.

 ★ C270 때는 "지나치면 위험한" 방향이 뚜렷했지만(48도까지 숙이면 8%
   손실 등), C920 은 후퇴가 0cm 라 화각 여유가 훨씬 커져서 40~78도
   사이는 전부 안전합니다. 각도기 앱으로 정확히 재서 이 범위 안에
   드는지만 확인하면 됩니다. 범위를 벗어난 것 같으면 selftest.py 로
   실측값을 넣어 다시 확인하세요:

python selftest.py --setback 0.0 --height 1.62 --tilt <잰각도>

 좌우 위치(90cm)는 생각보다 관대합니다. 10cm 어긋나도 99.7% 는
 그대로 보입니다. 그래도 바닥에 테이프로 중앙선을 그어두면 편합니다.

 각도 재는 법
   휴대폰 "수평계" 또는 "각도기" 앱을 켜서 카메라 몸통 위에 올려놓고
   43도가 나오게 맞춥니다.

 확인할 것
   - 삼각대 다리가 카메라 자기 화면에 들어오지 않는가
     (들어오면 카메라를 삼각대 기둥보다 앞으로 내밀어야 합니다)
   - 한번 세운 뒤에는 절대 건드리지 않기
     카메라가 1cm만 움직여도 5단계부터 전부 다시 해야 합니다.
     삼각대 다리를 테이프로 바닥에 고정해두면 좋습니다.


====================================================================
 5단계. 바닥 마커 붙이기 (화면 보면서)
====================================================================

 여기서부터는 화면을 보면서 작업합니다.

 (1) 검은 창에 아래를 치고 엔터:

python place_markers.py

 (2) 창이 세 개 뜹니다.

     STATUS  : 이것만 보면 됩니다. 마커별로 어느 카메라가 보는지 표시
     cam0    : 0번 카메라 영상
     cam1    : 1번 카메라 영상

     STATUS 화면은 이렇게 생겼습니다:

       MARKER      CAM0          CAM1          RESULT
       ID 1        OK 118px      OK  94px      BOTH OK
       ID 2        OK 120px      -- not seen   NEED BOTH
       ID 3        -- not seen   OK 102px      NEED BOTH
       ID 4        OK 114px      OK  98px      BOTH OK
       ID 0        OK  80px      OK  78px      BOTH

       cam0: floor 3/4          cam1: floor 3/4
       reproj -- --             reproj -- --

     초록색 "BOTH OK" 가 뜨면 두 카메라가 다 보고 있다는 뜻입니다.
     빨간색 "not seen" 이 뜨면 그 카메라가 못 보는 것입니다.

 (3) 목표 위치에 마스킹테이프로 십자 표시 4개를 만듭니다.

     1번 마커 -> 오른쪽 10cm,  뒤로 40cm
     2번 마커 -> 오른쪽 170cm, 뒤로 40cm
     3번 마커 -> 오른쪽 10cm,  뒤로 140cm
     4번 마커 -> 오른쪽 170cm, 뒤로 140cm

     위에서 내려다본 그림:

                        카메라 B
                           ^
                           | 벽 바로 앞 (후퇴 없음)
     ============================================  <- 뒤쪽 벽 (y=180)
     |        [장난감상자]      [체스상자]       |   상자 자리 (y=145~180)
     |------------------------------------------|  y=140  작업영역 끝
     | [3번]                             [4번]  |   y=140
     |                                          |
     |         로봇이 다니는 곳 (180 x 100)      |
     |                                          |
     | [1번]                             [2번]  |   y=40
     |(0,0)--------------------------------------  y=40  작업영역 시작
     |            (앞쪽은 비워 둡니다)            |
     ============================================  <- 앞쪽 벽 (y=0)
       x=10          x=45     x=135       x=170
                           |
                           | 벽 바로 앞 (후퇴 없음)
                           v
                        카메라 A

     마커 4장이 만드는 사각형 : 가로 160cm x 세로 100cm
     (작업 영역의 네 귀퉁이와 같습니다)

     ★ 왜 이 자리인가요?

       1) 최대한 넓게 벌립니다
          넓을수록 좌표가 정확해집니다.
          가로 100cm 면 오차 4.3mm, 160cm 면 2.7mm 입니다.
          160cm 를 넘으면 더 좋아지지 않으니 이쯤이면 충분합니다.

       2) 상자와 좌우 위치가 겹치지 않게 합니다
          상자는 높이 22cm 라 바닥에 20cm 짜리 그림자를 만듭니다.
          마커가 그 그림자에 들어가면 그쪽 카메라가 마커를 통째로
          못 봅니다. 상자를 가운데 쪽(45cm, 135cm)에 두었기 때문에
          마커(10cm, 170cm)와 18cm 떨어져 그림자가 닿지 않습니다.

       3) 결과적으로 작업 영역의 네 귀퉁이가 됩니다
          외우기 쉽습니다. 앞뒤로 40cm / 140cm, 좌우로 10cm / 170cm.

 (4) 마커를 한 장씩 십자에 맞춰 놓고, STATUS 화면을 봅니다.

     "BOTH OK" 가 뜨면          -> 그 자리에 붙입니다
     한쪽만 보이면              -> 조금 옮겨보고 다시 확인
     둘 다 안 보이면            -> 아래 "안 보일 때" 참고

     붙이기 전에 손으로 들고 위치를 잡아보면 편합니다.

 (5) 네 장 모두 "BOTH OK" 가 되면 붙입니다.

     ★★★ 제일 중요한 것 ★★★

     네 장 모두 "종이의 위쪽"이 뒤쪽 벽을 향하게 붙이세요.

     네 장이 전부 같은 방향이어야 합니다. 한 장이라도 옆으로 돌아가
     있으면 프로그램이 로봇 위치를 완전히 엉뚱하게 계산합니다.
     (증상: 9단계에서 reproj 가 10, 50 처럼 크게 나옵니다)

 (6) 다 붙였으면 STATUS 아래쪽 reproj 를 봅니다.

     아직은 config.py 에 기본 숫자가 들어 있으니 정확하지 않습니다.
     8단계에서 실제로 잰 숫자를 넣은 뒤에 다시 확인하면 됩니다.

 (7) q 를 눌러 끝냅니다.


 마커가 안 보일 때

   - 방이 어두운가? 불을 켜세요.
   - 마커에 그림자가 지거나 형광등이 반사되는가?
   - 마커가 우글거리는가? 평평하게 펴세요.
   - 화면에 나오는 px 숫자가 40 보다 작은가?
     -> 너무 멀거나 마커가 작습니다. 안쪽으로 옮기거나 크게 인쇄하세요.
   - 앞뒤 벽에 너무 붙었는가? 벽에서 30cm 보다 안쪽으로 옮기세요.

 ※ 이 프로그램은 아무것도 저장하지 않습니다.
   마음껏 붙였다 뗐다 하면서 확인하세요.


====================================================================
 6단계. 로봇에 마커 붙이기
====================================================================

 0번 마커(marker_0_robot.png)를 로봇 맨 윗판 한가운데에 붙입니다.

 확인할 것
   - 마커가 수평인가 (기울어지면 안 됩니다. 로봇을 평평한 바닥에 두고
     마커 위에 작은 물병을 올려봐서 안 구르면 대체로 수평입니다)
   - 마커 한가운데가 로봇의 회전 중심 바로 위에 있는가
   - ★ 종이의 위쪽이 로봇이 앞으로 갈 방향을 향하는가

 마지막 항목을 그림으로 보면 이렇습니다. 로봇을 위에서 내려다본 모습:

           로봇이 가는 방향
                 ^
                 |
          +-------------+
          |  종이 위쪽   |
          |             |
          |  [마커무늬]  |     <- 종이의 "위"가 로봇 앞을 향한다
          |             |
          |  종이 아래   |
          +-------------+
             (로봇 몸통)

 프로그램은 이렇게 붙였다고 보고 각도를 계산합니다.
 (config.py 의 YAW_OFFSET_DEG = 90.0 이 그 뜻입니다. 이대로 붙였으면
  이 숫자는 건드리지 마세요.)

 다른 방향으로 붙였어도 괜찮습니다. 9단계에서 숫자로 고칠 수 있습니다.

 붙인 뒤 place_markers.py 를 다시 돌려서 ID 0 이 "BOTH" 로 뜨는지
 확인하면 좋습니다. 로봇을 여기저기 옮겨보면서 어디까지 보이는지
 눈으로 확인할 수 있습니다.


====================================================================
 7단계. 자로 재서 숫자 적어두기  ★가장 중요★
====================================================================

 여기가 제일 중요합니다. 아래 표에 연필로 적어두세요.
 재는 기준은 전부 "마커 중심" 입니다. (앞의 설명 참고)

 (가) 바닥 마커 4장의 진짜 위치

   붙이려던 자리와 실제로 붙은 자리는 몇 mm 다릅니다.
   붙인 다음에 실제 위치를 재세요.

   두 가지 방법이 있습니다. 편한 쪽을 고르세요.

   ---- 방법 1 (쉬움) : 1번 위치 + 가로폭 + 세로만 재기 ----

     긴 거리를 구석에서부터 재는 건 어렵습니다. 마커끼리 재는 게
     훨씬 쉽고 정확합니다. 네 장을 직사각형으로 붙였다면 이걸로 충분합니다.

       1번 마커 위치   오른쪽 [      ] cm,  뒤로 [      ] cm
       가로폭 (1번↔2번 중심거리)        [      ] cm
       세로   (1번↔3번 중심거리)        [      ] cm

     검산용 (꼭 재세요)
       대각선 1번↔4번  [      ] cm
       대각선 2번↔3번  [      ] cm

   ---- 방법 2 (정확) : 4장을 각각 재기 ----

     비뚤어지게 붙었어도 그대로 반영됩니다.
     재는 방법: 출발점(0,0) 구석에서 마커 중심까지의 거리

       1번 마커  오른쪽 [      ] cm,  뒤로 [      ] cm
       2번 마커  오른쪽 [      ] cm,  뒤로 [      ] cm
       3번 마커  오른쪽 [      ] cm,  뒤로 [      ] cm
       4번 마커  오른쪽 [      ] cm,  뒤로 [      ] cm

   밀리미터까지 적으세요. 예: 40.3 cm

   ★ 어느 방법이든 대각선 검사를 하세요.
     1번↔4번 과 2번↔3번 의 차이가 5mm 이내여야 직사각형입니다.
     (8단계 계산기가 자동으로 확인해 줍니다)

 (나) 로봇 마커의 높이

   로봇을 바닥에 두고, 바닥에서 마커 종이의 윗면까지 높이를 잽니다.

     로봇 마커 높이 [      ] cm

   ※ 이 숫자가 1cm 틀리면 로봇 위치가 1.3cm 틀어집니다.
     밀리미터까지 정확히 재세요. 예: 20.4 cm
     여기가 제일 자주 틀리는 곳입니다.

 (다) 마커 크기 (1단계에서 인쇄한 실제 크기)

     검은 사각형의 바깥 변을 잽니다. 흰 여백은 빼세요.

     로봇 마커(0번) 한 변 [      ] cm   (8.0 근처)
     바닥 마커(1~4번) 한 변 [      ] cm   (12.0 근처)

     바닥 마커 4장은 서로 같은 크기여야 합니다.

     * 12.0 이 아니어도 됩니다. 나온 대로 정직하게 적으세요.

 (라) 상자 위치 — 물건을 분류해서 담을 상자 2개입니다

   상자는 크기 21 x 35 x 22 cm (폭 x 길이 x 높이) 이고,
   둘 다 작업 영역 "바깥" 인 뒤쪽 40cm 띠에, 가운데를 기준으로
   좌우 같은 거리에 놓습니다.

     장난감 상자   오른쪽 [    ] cm, 뒤로 [    ] cm
     체스 상자     오른쪽 [    ] cm, 뒤로 [    ] cm

   적는 값은 상자의 "중심" 위치입니다.

   ★ 권장값 : 오른쪽 45cm / 135cm,  뒤로 162.5cm

     좌우 (가운데 90cm 에서 45cm 씩)
       가운데에서 45cm 씩 떼면 마커(10cm, 170cm)와 18cm 떨어집니다.
       상자 그림자가 마커에 닿지 않고, 로봇이 상자 앞에 서도
       마커까지 35cm 라 밟지 않습니다.

       얼마나 떼도 되는지 계산해 봤습니다:

           가운데에서 35cm  ->  마커까지 28cm 여유. 좋음
           가운데에서 45cm  ->  마커까지 18cm 여유. 좋음  <- 권장
           가운데에서 55cm  ->  로봇이 마커를 밟을 수 있음
           가운데에서 63cm  ->  상자가 마커와 겹침. 안 됨

       35~45cm 사이에서 편한 값을 쓰시면 됩니다.

     앞뒤 (뒤로 162.5cm)
       길이가 35cm 이므로 뒤로 145 ~ 180cm 를 차지합니다.
       뒤쪽 벽에 딱 붙는 위치입니다.
       작업 영역이 140cm 에서 끝나니 겹치지 않습니다.

   ★ 상자를 작업 영역 안(뒤로 40~140cm)에 넣지 마세요.
     거기는 로봇과 옮길 물건만 있는 곳입니다.
     실수로 겹치게 적으면 selftest 가 잡아냅니다.

   ★ 상자를 앞으로 당기지 마세요.
     상자가 앞으로 나올수록 그림자가 길어집니다.
     뒤쪽 벽에 최대한 붙이는 게 좋습니다.


====================================================================
 8단계. 컴퓨터에 숫자 넣기
====================================================================

 7단계에서 적어둔 숫자를 컴퓨터에 알려줍니다.

 (1) 먼저 config.py 를 복사해서 config_원본.py 로 하나 남겨둡니다.
     (잘못 고쳤을 때 되돌리려고)

 (2) config.py 를 마우스 오른쪽 클릭
     -> "연결 프로그램" -> "메모장" 으로 엽니다.

 ※ 주의: 여기 숫자는 cm 가 아니라 "미터" 입니다!
    센티미터를 100으로 나눠서 적으세요.
      20.4 cm  ->  0.204
      40.3 cm  ->  0.403
      12.0 cm  ->  0.120

 고칠 곳 1) 로봇 마커 높이

     ROBOT_MARKER_HEIGHT = 0.200

   0.200 자리에 7단계 (나) 에서 잰 높이를 미터로 적습니다.

 고칠 곳 2) 마커 크기 (두 줄이 서로 다릅니다)

     ROBOT_MARKER_SIZE = 0.080     <- 로봇용 8cm
     FLOOR_MARKER_SIZE = 0.120     <- 바닥용 12cm

   7단계 (다) 에서 잰 크기를 미터로 적습니다.
   로봇 마커가 7.9cm 였으면 0.079, 바닥이 12.3cm 였으면 0.123.

   ★ 검은 사각형만 재세요. 종이 크기(10cm)가 아닙니다.

 고칠 곳 3) 바닥 마커 4장의 위치

     FLOOR_MARKER_WORLD = {
         1: (0.100, 0.400),
         2: (1.700, 0.400),
         3: (0.100, 1.400),
         4: (1.700, 1.400),
     }

   괄호 안은 (오른쪽으로 몇 미터, 뒤로 몇 미터) 입니다.

   ★ 이건 손으로 계산하지 말고 계산기를 쓰세요.
     cm 로 넣으면 알아서 미터로 바꾸고 검산까지 해 줍니다.

     방법 1 로 쟀다면 (1번 위치 + 폭 + 세로):

python make_layout.py --x1 10.2 --y1 40.1 --width 160.4 --depth 100.2 --diag14 189.0 --diag23 188.6

     방법 2 로 쟀다면 (4장 각각):

python make_layout.py --m1 10.2 40.1 --m2 170.5 40.0 --m3 10.1 140.4 --m4 170.6 140.2

     숫자는 자기가 잰 값으로 바꿔 넣으세요.

     결과가 이렇게 나옵니다:

         대각선 1-4 : 188.8 cm     2-3 : 188.8 cm  (차이 0 mm)
         마커가 차지하는 범위 : 가로 160.4 cm x 세로 100.2 cm
         세로 위치 30~150 cm 범위 안 : OK
         상자 그림자 피함 : OK

         config.py 에 넣을 내용
         FLOOR_MARKER_WORLD = {
             1: (0.102, 0.401),
             ...
         }

     "상자 그림자 피함" 이 OK 가 아니면 마커가 상자 바로 뒤에 있다는
     뜻입니다. 마커를 좌우로 더 빼서 상자를 피하세요.

     이 내용을 config.py 에 옮겨 적으면 됩니다.
     직접 옮기기 귀찮으면 명령 맨 뒤에 --write 를 붙이세요.
     프로그램이 config.py 를 알아서 고치고, 원본은 config_backup.py 로
     남겨둡니다.

     경고가 뜨면 --write 를 붙여도 반영하지 않습니다. 다시 재세요.

 고칠 곳 4) 상자 위치

     BOXES = {
         "toy":   (0.450, 1.625, 180.0),
         "chess": (1.350, 1.625, 180.0),
     }

   앞의 두 숫자가 상자 "중심"의 위치입니다 (미터).
   세 번째 숫자는 상자가 바라보는 각도인데, 뒤쪽 벽에 붙여 작업 영역을
   향해 열어 두면 180.0 입니다.

 (3) 다 고쳤으면 저장합니다. (Ctrl 키를 누른 채로 S)

 (4) ★ 잘 고쳤는지 확인합니다. 검은 창에 아래를 치고 엔터:

python selftest.py

     맨 아래에 "26/26 PASS" 가 나오면 파일도 멀쩡하고 배치도 성립합니다.

     빨간 글씨로 SyntaxError 가 뜨면 고치다 글자를 잘못 지운 것입니다.
     config_원본.py 로 되돌리고 숫자만 다시 고치세요.

     FAIL 이 뜨면 숫자는 멀쩡하지만 배치에 문제가 있다는 뜻입니다.
     어느 항목이 FAIL 인지 보고 7단계로 돌아가세요.

 ★ 조심할 것
   - 숫자만 고치세요. 글자나 괄호, 쉼표를 지우면 안 됩니다.
   - 쉼표(,)와 마침표(.)를 헷갈리지 마세요. 0.204 가 맞고 0,204 는 틀립니다.


====================================================================
 9단계. 실행해서 확인하기
====================================================================

 (1) 검은 창에 아래를 치고 엔터:

python run_localize.py

 (2) 카메라 화면 2개가 뜹니다. 화면에서 이걸 확인하세요:

     - 바닥 마커에 초록색 네모와 숫자(1,2,3,4)가 그려지는가
     - 로봇 마커에 주황색 네모와 숫자(0)가 그려지는가
     - 화면 위쪽에 floor=4/4 라고 나오는가
     - ★ reproj 숫자가 1.00 보다 작은가
     - [locking 0/30] 이 1~2초 안에 [LOCKED] 로 바뀌는가

       LOCKED 가 되기 전까지는 바닥 마커 4장이 다 보이게 두세요.
       LOCKED 가 된 뒤에는 로봇이 마커를 밟아도 괜찮습니다.

       reproj 1.0 미만  ->  잘 쟀습니다
       reproj 1.0 ~ 2.0 ->  그럭저럭. 급하지 않으면 다시 재보세요
       reproj 2.0 넘음  ->  7단계로 돌아가 다시 재세요
       reproj 3.0 넘음  ->  값이 아예 안 나옵니다

 (3) 아래쪽에 이런 숫자가 나옵니다:

     x=  900.0mm  y=  900.0mm  yaw=   0.0deg  cams=2

     x, y  = 로봇이 출발점에서 오른쪽/뒤로 몇 mm 인지
     yaw   = 로봇이 어느 쪽을 보고 있는지 (각도)
     cams  = 지금 로봇을 보고 있는 카메라 대수 (2가 제일 좋음)

 (4) 맞는지 확인하는 법

     로봇을 놓고, 줄자로 실제 위치를 잽니다.
     화면 숫자와 비교하세요. 3cm 안쪽으로 맞으면 성공입니다.

     자리를 3~4군데 바꿔가며 해보세요. 이럴 때 확인하면 좋습니다:
       - 한가운데 (90, 90)
       - 네 귀퉁이 쪽 (10, 45) (170, 45) (10, 135) (170, 135)

     ※ 로봇을 앞뒤 벽 쪽 상자 자리에 넣지는 마세요.
       뒤로 40cm 보다 앞이나 140cm 보다 뒤는 작업 영역 밖입니다.
       거기 들어가면 노란 글씨로 "OUT OF WORKSPACE" 가 뜹니다.

 (5) 각도(yaw)가 이상할 때

     먼저 정상인 경우를 알아둡시다.
     로봇을 오른쪽(x가 커지는 쪽)을 향하게 놓으면 yaw 가 0 이 나와야
     합니다. 뒤쪽을 향하면 90, 왼쪽이면 180, 앞쪽이면 -90 입니다.

               yaw = 90 (뒤쪽)
                    ^
                    |
      yaw = 180 <---+---> yaw = 0 (오른쪽)
       (왼쪽)       |
                    v
              yaw = -90 (앞쪽)

     이상하면 이렇게 고칩니다.

     (가) 로봇을 오른쪽(x가 커지는 쪽)을 향하게 똑바로 놓습니다.
     (나) 화면에 나오는 yaw 숫자를 읽습니다. 이걸 A 라고 합시다.
     (다) config.py 를 메모장으로 열어 아래 줄을 찾습니다.

              YAW_OFFSET_DEG = 90.0

     (라) 90.0 에서 A 를 뺀 값으로 고칩니다.

              예) A 가 90 이었다면   ->  90 - 90  =  0.0
              예) A 가 -90 이었다면  ->  90 + 90  =  180.0
              예) A 가 45 였다면     ->  90 - 45  =  45.0

     (마) 저장하고 다시 실행해서 0 이 나오는지 확인합니다.

 (6) 끝낼 때는 카메라 화면을 클릭하고 q 키를 누릅니다.

====================================================================
 카메라 없이 미리 연습하기
====================================================================

 웹캠을 아직 못 구했어도 프로그램이 잘 돌아가는지 확인할 수 있습니다.
 컴퓨터 안에 가짜 카메라를 만들어서 시험하는 기능입니다.

python selftest.py

 맨 아래에 "26/26 PASS" 가 나오면 프로그램은 정상입니다.

 ★ 8단계에서 config.py 를 고친 다음에는 꼭 한 번 돌려보세요.
   숫자를 잘못 고쳤거나 배치가 성립하지 않으면 여기서 바로 걸립니다.

 FAIL 이 나올 때 보는 법

   "SyntaxError" 또는 "IndentationError"
       -> config.py 를 고치다 글자를 잘못 지웠습니다.
          config_원본.py 로 되돌리고 숫자만 다시 고치세요.

   "camA/camB 바닥 마커 가시" 가 FAIL (2/4, 3/4 로 나옴)
       -> 마커가 상자 그림자에 들어갔거나 카메라 화각을 벗어났습니다.
          마커를 상자와 좌우로 겹치지 않게 옮기세요.

   "선언한 작업 영역 안에 사각지대가 없다" 가 FAIL
       -> 카메라 배치값과 작업 영역이 안 맞습니다.
          4단계 배치를 바꿨다면 범위를 다시 계산해야 합니다.

   "상자가 모두 작업 영역 밖에 있다" 가 FAIL
       -> 상자 좌표가 작업 영역(뒤로 40~140cm)과 겹칩니다.
          상자를 뒤쪽 벽으로 더 붙이세요.


====================================================================
 잘 안될 때
====================================================================

 [증상] 검은 창에 "'python'은(는) 내부 또는 외부 명령... " 이라고 뜬다
   -> 파이썬이 설치 안 된 것입니다. python 대신 py 를 쳐보세요.
      그래도 안 되면 파이썬을 다시 설치해야 합니다.

 [증상] "ModuleNotFoundError: No module named 'cv2'" 라고 뜬다
   -> 아래를 치고 엔터:
      python -m pip install opencv-python

 [증상] "열린 카메라가 하나도 없습니다" 라고 뜬다
   -> USB 를 뽑았다 다시 꽂고, 2단계를 다시 해서 번호를 확인하세요.
      번호가 0,1 이 아니면 이렇게 번호를 알려주세요:
      python run_localize.py --cams 1 2

 [증상] 카메라 화면은 뜨는데 마커에 네모가 안 그려진다
   -> 방이 어두울 수 있습니다. 불을 켜세요.
   -> 마커에 그림자가 지거나 빛이 반사되고 있을 수 있습니다.
   -> 마커가 너무 멀거나 화면 밖에 있을 수 있습니다.
   -> place_markers.py 를 켜서 px 숫자를 보세요.
      40 보다 작으면 너무 멀거나 마커가 작은 것입니다.

 [증상] floor 가 4/4 가 아니라 2/4, 3/4 로 나온다
   -> 안 잡히는 마커가 뭔가에 가려져 있거나 화면 밖입니다.
      place_markers.py 로 어느 마커를 못 보는지 확인하세요.
      2/4 여도 일단 돌아가긴 하지만 4/4 가 훨씬 정확합니다.

 [증상] reproj 숫자가 10, 50 처럼 크게 나온다
   -> 십중팔구 바닥 마커 방향이 틀렸습니다.
      네 장 모두 종이 위쪽이 뒤쪽 벽을 향하는지 다시 보세요.
   -> 아니면 config.py 에 적은 마커 위치가 실제와 다릅니다.
      7단계로 돌아가 다시 재세요.
   -> 마커 크기를 잘못 적었을 수도 있습니다.

 [증상] reproj 가 1~3 사이로 애매하다
   -> 재기 오차가 5~10mm 쯤 됩니다. 작동은 하지만 정확도가 떨어집니다.
      대각선 검사(7단계 가)부터 다시 해보세요.

 [증상] ROBOT LOST 라고만 나온다
   -> 로봇 마커(0번)가 안 보이는 것입니다.
      로봇이 앞뒤 벽에 너무 붙어 있으면 안 보입니다. 안쪽으로 옮기세요.
      작업 영역(뒤로 40 ~ 140cm) 안이면 항상 보입니다.
      좌우 벽은 붙어 있어도 괜찮습니다.
   -> 로봇 마커가 뭔가에 가려졌을 수도 있습니다.

 [증상] "OUT OF WORKSPACE" 라는 노란 글씨가 뜬다
   -> 로봇이 작업 영역 밖(앞뒤 40cm 상자 자리)에 나갔다는 뜻입니다.
      숫자는 나오지만 곧 놓칠 수 있습니다. 안쪽으로 옮기세요.

 [증상] 위치는 나오는데 실제와 5cm 이상 차이난다
   -> 로봇 마커 높이를 다시 재세요. 여기가 제일 자주 틀립니다.
   -> 3단계 캘리브레이션을 안 했거나 RMS 가 컸을 수 있습니다.
   -> 바닥 마커 위치를 다시 재세요.

 [증상] 갑자기 전부 이상해졌다
   -> 카메라나 삼각대를 건드렸는지 확인하세요.
      건드렸으면 4단계부터 다시 해야 합니다.
