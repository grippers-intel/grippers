# 채택하지 않은 설계와 근거

> "못 한 것"이 아니라 "판단해서 뺀 것"을 기록한다.
> 각 항목에는 가능한 한 실측값 또는 정량 근거를 붙인다.

## 1. 파지 변경 방식

| 방식 | 내용 | 걸림돌 | 판정 |
|---|---|---|---|
| **자세 재조정** | 손목 피치 회전으로 각도만 변경 | — | **채택 (MVP)** |
| 파지점 이동 | 내려놓고 다른 지점 재파지 | 거치대 필요. **내려놓기 = 오염** (멸균 시나리오와 충돌) | 확장 과제 (M3 여유 시) |
| 핸드오버 | 두 그리퍼 간 전달 | 두 번째 암 필요. 인핸드 조작은 미해결 연구 영역 | 제외 |

## 2. 이송 방식

| 방식 | 걸림돌 | 판정 |
|---|---|---|
| 차체 트레이 적재 | 좁은 출구를 그냥 통과하게 되어 **자세 재조정의 존재 이유가 사라짐** | 제외 |
| 암이 든 채 이동 | 주행 안정성과 상충 → 저속 프로파일로 완화 | 채택 |

## 3. 이동 구조

| 방식 | 걸림돌 | 판정 |
|---|---|---|
| 레일 / 갠트리 | 작업 영역이 고정됨. "레일 없는 곳" 문제 정의와 모순 | 변경 |
| 메카넘 휠 카 | 슬립으로 오도메트리 열화 → 마커 도킹으로 보완 | 채택 |

## 4. AI 가속기

| 후보 | 걸림돌 | 판정 |
|---|---|---|
| **Hailo-10H (M.2 모듈)** | 8L 대비 소비전력·발열 증가, M.2 HAT+ 캐리어 별도 필요 | **채택** |
| Hailo-8L (AI HAT+) | **온보드 메모리 없음 → VLA-L(트랜스포머) 상주 시도 자체가 불가.** YOLO 가속은 가능하나 확장 여지 없음. 지원 모델 제한, 전용 컴파일 | 폴백 (10H 수급 실패 시 — YOLO만 가속하는 축소 구성) |
| Intel NPU + OpenVINO | **Pi에 직접 연결 불가 — 별도 x86 보드 필요.** 무게·전력·배선·전원 도메인이 전부 바뀜 | 제외 |
| Coral Edge TPU | TF-Lite 한정, 최신 YOLO 지원 취약 | 제외 |
| CPU only | 실시간 추론 불가 | 기준선 |

## 6. ROS2 노드 분할

| 방식 | 걸림돌 | 판정 |
|---|---|---|
| 기능 축 분할 (주행/회피/파지) | 순차 단계라 동시성 이득 없음. 직렬화 지연·분산 상태·디버깅 불가 | 제외 |
| 회피기동 독립 노드 | `/cmd_vel` 발행 주체가 2개 → 명령 경합, 재현 불가 버그 | 제외 |
| 동시성·디바이스 소유 기준 분할 | — | 채택 |
