## 4. 알려진 한계

| 한계 | 내용 · 현재 대응 |
|---|---|
| **학습한 6가지 기물만** | 검출(Geti)은 6개 라벨, 지시 해석도 보이는 라벨 안에서만, ACT 는 그 기물 시연으로 학습 — 새 물건은 재학습 필요(→ handover "다음 단계") |
| 재기동 직후 무응답 | 드물게(재기동 5 s 뒤 27번 중 1번) — Host 자동 복구(약 13 s)가 처리. 원인은 보드 펌웨어 쪽으로 추정 |
| 유령 필터의 절충 | 쥔 동안 로봇 40 cm 안에 처음 나타난 검출은 쥔 기물로 보고 피하지 않는다 — 그 자리에 실제 기물이 있으면 놓칠 수 있다 |
| 건넨 기물 | 건넨 뒤 60 s 동안 손 자리 45 cm 안 같은 라벨은 지도에서 뺀다 — 그 사이 근처에 내려놓은 기물은 60 s 뒤부터 보인다 |
| 회전 중 ESTOP | 관성으로 7° 더 돌아 "ESTOP 인데 돈다" 폭주로 보고 보드 리셋을 한 번 요청(무해) |
| 시뮬의 꺾이는 운반 | 시뮬은 짧은 회전 뒤 흐름을 크게 봐서 꺾이는 운반이 실기보다 많다 — 비교용으로만 |
| DP 보류 | 개선 후보(샘플링 횟수 · 관측 프레임 · 청크 길이)는 handover 와 팀 아티팩트 "DP 파지 개선 과제" |
