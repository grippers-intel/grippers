# 결정 기록

> 무엇을 왜 그렇게 정했는가 — 그리고 무엇을 뺐는가. 날짜는 결정한 날, 값은 지금 설정(2026-10-13).
> 원문(문제 · 근거 · 실측 표)은 팀 Obsidian `vla_robot/결정/` 에 있습니다. 초기 설계에서 뺀 것은 [legacy rejected_designs](../legacy/docs/ops/rejected_designs.md).

## 구조

| 결정 | 왜 | 대신 버린 것 |
|---|---|---|
| **공간은 Host 가, 실행은 Pi 가** — 명령에 좌표가 없다 | 위치 오차의 원인을 한 곳(탑뷰)에 모은다. Pi 는 속도 · 팔 작업만 | Pi 가 뎁스 · 라이다로 "다시 세워 달라" 요청하던 경로(GRASP_ALIGN · INSERT_ALIGN) |
| **작업 결과는 매 패킷 반복** (09-14) | UDP 에서 한 번 보내는 완료 보고는 사라질 수 있다 — Host 가 GRASP 에 갇혔다 | 완료 사건 한 번 보내기 + 우선순위 땜질 |
| **규격 · 캘리브레이션은 한 벌** (09-14) | 같은 포트에 서로 못 알아듣는 규격 두 벌이 돌았다 · 비슷한 캘리브레이션 JSON 40여 개 | — `protocol.py` 하나, `arm_calibration.json` 하나(EEPROM 과 다르면 기동 거부) |
| **탑뷰 ArUco 로 로봇 위치** | 카메라 2대 + 마커로 절대 위치 · 방향을 바로 얻는다 | 초기 설계의 뎁스 카메라(RealSense, 폐기) · 라이다 기반 정렬 |

## 인식

| 결정 | 왜 | 대신 버린 것 |
|---|---|---|
| **기물 검출은 Geti 모델을 노트북 내장 그래픽(OpenVINO GPU.0)에서** (10-12) | Host CPU 대기 21.9 → 11.1 % · 작업 46.6 → 19.0 %, 결과 같음(1 mm 안) | CPU 검출(발열) · 외장 RTX 3050(OpenVINO 커널 없음) · Hailo(초기 설계) |
| **손은 MediaPipe, 두 카메라 광선 교차로 높이까지** (10-01) | 학습 없이 바로 쓴다. 고정 높이로 풀면 든 손이 두 개로 갈라졌다(24 cm) | 손 전용 검출 학습 |
| **파지 판정은 그리퍼캠 영상으로** (09-22) | 빈손 0~10 % · 쥠 26~82 % 로 확실히 갈린다. 기준 18 %(09-30 상향) | 그리퍼 개도 · 부하(TPU 재질에서 쥠과 빈손이 안 갈림) |

## 파지 · 팔

| 결정 | 왜 | 대신 버린 것 |
|---|---|---|
| **파지 정책은 ACT 12만 스텝, Pi CPU** (10-12) | 같은 날 같은 장판에서 ACT 86 %(6/7) · DP 43 %(6/14), DP 는 느리고(7~10 청크) 노트북이 뜨거워짐 | Diffusion Policy 6만(노트북 GPU 서버) — `robot_dp.yaml` 로 보류 |
| **파지 시작 거리는 범위 0.26–0.31 m** (09-30) | 정면을 맞춰도 빈손이 거리로 갈렸다 — 범위 안으로 조금씩 맞춘다 | 한 점 거리 |
| **그리퍼는 보낸 목표를 이어 쓴다** (09-30) | 쥔 채 자세를 옮길 때 목표를 다시 쓰면 살짝 벌어져 떨어졌다 | 자세마다 그리퍼 값 다시 쓰기 |
| **정책 입력은 RGB** (09-14) | 전선(토픽)은 BGR, 정책 직전 한 곳에서만 바꾼다 | 경로마다 다른 변환 |

## 주행 · 투입

| 결정 | 왜 | 대신 버린 것 |
|---|---|---|
| **바구니 정렬은 팔의 base 가** (09-22) | 차체는 몇 도짜리 회전을 못 내고, 제자리 회전이 위치 추정을 흔든다. 차는 정면에 서고 남는 각(±15°)은 팔이 | 차체로 호 위에서 정렬 |
| **상자 앞 정차 0.22 m — 거기서 돈다** (09-30) | 0.15 m 에서는 제자리 회전 반지름이 상자를 넘어 쳤다 | 0.15 m 정차 |
| **바구니에는 정차 구역(가운데 ±10 cm)으로** (10-07) | 정차점이 한 점이면 옆 기물 때문에 설 수 없었다 — 구역에서 비는 자리를 고른다 | 고정 정차점 하나 |
| **바구니 접근은 회전 → 직진 → 회전 → 투입 한 모양** (10-08) | 기물마다 꺾는 횟수가 달랐다. 실기 운반 41번 중 39번이 이 모양 | 경로 중간점 · 허용치 끝 정지가 겹친 접근 |
| **가져와는 손 앞 정차점에서 ㄱ자로 건넨다** (10-01) | 손에 직접 닿지 않고 사람이 받기 쉬운 높이 · 자세. 열기 전 1 s 대기 | 바닥에 내려놓기 |
| **정차 소음은 서 있는 동안 컨트롤러 재기동으로** (10-05) | 회전 뒤 바퀴 "지잉" — 보드 속도 제어 잔여값. 재기동하면 바로 멎는다(약 6 s, 팔 작업 시간에 숨음) | 반대로 짧게 돌아 풀기(10-01 → 10-08 제거) |
| **오래 서 있다 첫 출발 전 미리 재기동** (10-12) | 60 s 넘게 쉬면 첫 명령을 무시하는 무응답 — 복구(13 s) 대신 미리(6 s) | 무응답 뒤 복구만 |
