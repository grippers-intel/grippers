## 학습이 실제로 들어가는 곳 — 두 군데

| # | 대상 | 방식 | 상태 |
|---|---|---|---|
| 1 | **물체 검출·분류** (perception) | YOLO 파인튜닝 | **MVP 범위.** 2범주. 분류 결과가 목적지 결정의 근거이며, **범주 내 형상 다양성이 일반화의 증거** |
| 2 | 파지 정책 (action) | 텔레오퍼레이션 시연 학습 | ⚠️ **Stretch로 강등 (8/13)** — 일정상 제외. **기하 계산이 MVP 경로** |

> [!IMPORTANT]
> **MVP에서 학습이 실제로 들어가는 곳은 물체 검출 하나입니다.** 파지는 기하 계산입니다.
> 일정 압박으로 파지 정책 학습을 Stretch로 내렸으며(→ [Milestones](#-milestones)),
> **발표에서도 이대로 서술합니다.** 여유가 생겨 정책 학습이 붙으면 추가 성과로 넣습니다.

## 학습하지 않는 것 — 그리고 그 이유

| 항목 | 방식 | 이유 |
|---|---|---|
| 자세 각도 `φ` *(보류)* | 닫힌 형태 해 | 부등식으로 풀림 — RL로 하면 근거가 없음 |
| 상자 탐색 | 색 세그멘테이션 (LAB) | 견고성 우선. 주행 목표이지 판단 근거가 아님 |
| 배치 규칙 | 설정 + 명령 | **사람이 정하는 것이 요구사항** |
| 상태 전이 | 상태 머신 | 학습할 자유도가 없음 |

> **`margin` 학습은 자세 재조정과 함께 보류되었습니다.** 대상 물체가 없어 적용할 곳이 없습니다.

## 실행 위치

| 구성 | 기법 | 실행 위치 |
|---|---|---|
| 물체 검출·분류 | YOLO 파인튜닝 | **Hailo-10H** (AI HAT+ 2) — Model Zoo 레퍼런스 존재 |
| 명령 해석 | 규칙 + 경량 파서 | **CPU (Pi 5)** |
| 치수·자세 추정 | 세그멘테이션 + 기하 | Hailo (세그) + CPU (기하) |
| 파지 (MVP) | **기하 계산** | CPU |
| 파지 정책 *(Stretch)* | 시연 학습 | CPU — 소형 정책망 |
| **STT / TTS** | whisper.cpp / Vosk | **노트북 (로봇 외부)** |

> [!NOTE]
> **"온디바이스"와 "Hailo 가속"은 다릅니다.** 로봇 측 구성 요소는 전부 온디바이스로 돌지만,
> **Hailo 가속 대상은 YOLO 계열 CNN 뿐**입니다. 나머지는 **CPU 추론을 기준선**으로 설계하며,
> Hailo 상주는 M2 컴파일 검증 후 얻는 업사이드로 취급합니다.

## 데이터

| 용도 | 수집 방법 | 규모 |
|---|---|---|
| 물체 검출 (2범주) | 실제 촬영 (일반 조명) | 범주당 200~250 인스턴스 |
| 상자 색 랜드마크 | LAB 튜닝용 촬영 | 학습 아님 |
| 파지 정책 *(Stretch)* | 리더/팔로워 텔레오퍼레이션 | 50~100 에피소드 — **M4 여유 시** |

리더/팔로워 암이 교육장에 있으므로 텔레오퍼레이션으로 시연 데이터를 직접 수집할 수 있습니다.
다만 **파지 정책 학습은 Stretch로 강등**되었으므로, 아래 수집 계획은 M4에 여유가 생겼을 때의 설계입니다.
MVP 경로는 기하 계산 기반 파지입니다.

### 시연 데이터는 라벨이 아니라 파지 형상으로 나눕니다

> [!IMPORTANT]
> **같은 물체를 라벨 수만큼 반복 시연하지 않습니다.** "체스말" · "검은색" · "퀸" 으로 세 번 찍어도
> **궤적이 동일**하므로 정보가 늘지 않고, 오히려 모델이 같은 상황을 다르게 학습하려다 방해받습니다.
>
> 정책의 입력은 라벨이 아니라 **검출된 자세와 치수**입니다:
> `GraspPolicy(pose_m, dims_m, yaw_rad) -> 궤적` — 여기에 `queen` 도 `black` 도 들어가지 않습니다.
> 범주 심볼은 **목적지를 고르는 데만** 쓰입니다.

| 파지 그룹 | 대상 | 에피소드 | 비고 |
|---|---|---|---|
| 평행면 파지 | 가베 (정육면체·기둥류) | 30~40 | 형상 4종 × 방향·거리 변화 |
| 넥 파지 | 체스말 전체 | 25~30 | 넥 통일 설계 → **기물 종류 무관, 그룹 1개** |
| 실패 복구 | 전 그룹 | 10 | 빗나간 뒤 재접근 — 유즈케이스 3 |

**다양성은 라벨이 아니라 조건에서 확보합니다** — 로봇 기준 방향(정면/좌/우/비스듬),
거리(근/중/원, 리치 한계 포함), 물체 자세(세움/눕힘), 주변 상황(단독/벽 근처/다른 물체 옆).
같은 가베라도 이 조합이 다르면 궤적이 실제로 다르므로 학습할 가치가 있습니다.

## 가속기 선택 근거

> 가산점 항목 — 선택 근거 문서화

| 단계 | 위치 | 근거 |
|---|---|---|
| **학습** | AI training server GPU | 데이터셋 규모·에폭 반복. 온디바이스로는 불가 |
| **추론** | 온디바이스 | 시연 시 네트워크 의존 제거, 지연 시간 확보 |

온디바이스 추론 가속기는 **Hailo-10H 채택 확정**이며, **Raspberry Pi AI HAT+ 2 실물을 보유**하고
**8/11 Pi 5 PCIe에 장착 완료**했습니다 (교수님 공수). 가속기 관련 발주 항목은 없습니다.

| 후보 | 성능 | 장점 | 단점 | 판정 |
|---|---|---|---|---|
| Pi 5 CPU only | — | 추가 부품 없음 | 실시간 검출 불가 | 기준선 |
| **Hailo-10H (AI HAT+ 2)** | 40 TOPS (INT4) | 8GB 온보드 LPDDR4X, Pi 5 PCIe 리본 직결, OS 자동 인식, 단일 품목 | 소비전력·발열 증가. **비전 처리량은 26 TOPS(Hailo-8)급** — 40 TOPS는 INT4 LLM/VLM 기준. PCIe 1포트 점유 | **✅ 채택 · 보유** |
| Hailo-8L (AI HAT+) | 13 TOPS | 저전력, 레퍼런스 풍부 | 온보드 메모리 없음 → 매 추론마다 가중치 스트리밍 | 미채택 |
| Intel NPU + OpenVINO | 가변 | 성숙한 툴체인, 팀 내 INT8 경험 | **Pi에 직접 연결 불가** — 별도 x86 보드 필요 | 제외 |

> [!CAUTION]
> **성능 예산에 40 TOPS를 쓰지 마세요.** 우리가 돌리는 것은 YOLO 계열 CNN이므로
> **26 TOPS급**으로 가정하고 프레임레이트를 계산해야 합니다. 40을 쓰면 M2에서 예산이 무너집니다.

## 모델 컴파일 파이프라인 (HEF)

학습한 모델을 Hailo에 **그대로 올릴 수 없습니다.** Hailo Dataflow Compiler(DFC)로 `.hef` 바이너리 컴파일이
필요하고, 지원 연산자 확인 + INT8 양자화 캘리브레이션에 **며칠 단위**가 걸립니다.

```
[ x86_64 Ubuntu 호스트 ] ── DFC는 여기서만 실행 (ARM 불가)      [ Pi 5 · ARM ]

  학습 (training server GPU)
        │
        ▼
   ONNX export  →  Hailo DFC
                     ├─ 지원 연산자 검사 (미지원 → 치환 또는 CPU 폴백)
                     ├─ INT8 양자화 캘리브레이션
                     └─ .hef 컴파일  ──── scp ───►  HailoRT 추론 검증
```

> [!WARNING]
> **DFC는 Pi에서 네이티브로 돌지 않습니다.** x86_64 Ubuntu 전용(WSL2 가능)이며 RAM 16GB 이상(32GB 권장),
> 일부 최적화는 NVIDIA GPU가 필요합니다. **팀에 x86_64 호스트가 없으면 HEF 일정 자체가 성립하지 않습니다.**
> AI training server 겸용 가능 여부 + **시연용 노트북 사양**을 함께 확인하세요 (미결 #6).

- `.onnx`, `.hef` 는 `.gitignore` 대상입니다. 컴파일 이력·연산자 이슈·측정치는 [`measurements.md`](../ops/measurements.md) 에 기록
- 지연·소비 전력·정확도 손실은 [`hld.md`](../design/hld.md) §성능 예산으로 올립니다
