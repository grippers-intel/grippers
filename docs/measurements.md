# 실측 리포트

> 추측하지 않고 측정한다. 모든 수치는 조건·시행 횟수와 함께 기록한다.

## 0. 측정 원칙

- 시행 횟수를 반드시 명시한다
- 성공률은 **이항분포 95% 신뢰구간**을 병기한다
- 조건(조명·페이로드·속도)을 통제하고 한 번에 하나만 바꾼다
- 원본 데이터는 `rosbag` 또는 CSV로 남긴다
